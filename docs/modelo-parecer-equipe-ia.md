# Meu Tutor IA — Modelo de parecer entre agentes (Etapa 7.3)

> Modelo para a Issue #10: canal piloto gratuito de troca de pareceres.
> Este documento não habilita comunicação automática entre IAs.

## Como usar
1. Trabalhe em **uma missão por vez**, referenciando a Issue correspondente.
2. Preencha os campos abaixo com fatos verificáveis. Quando não houver acesso, escreva **não verificado**; não invente testes, acesso ou resultados.
3. Se o fundador encaminhar um parecer de outra IA, registre **encaminhado pelo fundador**; não afirme que o agente publicou diretamente.
4. Consulte os pareceres anteriores antes de propor a próxima ação, quando estiverem disponíveis.
5. Nunca inclua chaves de API, tokens, senhas, dados privados ou conteúdo sensível.
6. Faça propostas em branch de testes; **sem merge, deploy, publicação ou execução automática**.

## Limites do piloto

- O GitHub registra e organiza pareceres; sessões gratuitas de IAs **não conversam sozinhas**.
- Nenhuma API paga, cartão, créditos ou token privado em comentários.
- Não resolver divergências automaticamente nem produzir relatório final automático nesta etapa.
- Um parecer é uma sugestão para revisão, não autorização para alterar produção.
